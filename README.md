# Week 4 – C Programming: Structures & File Handling

This repository contains my Week 4 internship work in C Programming.

The work focuses on structures, nested structures, file handling, reading and writing files, and command line arguments.

## Topics Covered

- Structures
- Nested Structures
- File Handling
- Reading from Files
- Writing to Files
- Command Line Arguments

## Assignments

### 1. Student Structure

A C program that creates a Student structure containing Name, Age, and Marks.

File: `assignments/01_student_structure.c`

### 2. Structure Data File Read and Write

A C program that writes student structure data to a file and reads the data back from the file.

File: `assignments/02_structure_file_read_write.c`

### 3. Count Number of Lines in a File

A C program that reads a file and counts the number of lines present in it.

File: `assignments/03_count_file_lines.c`

### 4. Append Data to Existing File

A C program that appends new data to an existing file without removing its previous contents.

File: `assignments/04_append_file.c`

## Mini Project – Employee Management System

An Employee Management System developed using C structures and file storage.

### Features

- Add Employee
- Display Employee Records
- Search Employee by ID
- Store employee records in a file
- Read employee records from the file
- Menu-driven interface

### Employee Details

The system stores:

- Employee ID
- Employee Name
- Employee Salary

File: `mini_project/employee_management_system.c`
